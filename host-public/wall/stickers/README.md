# Соболь РЯДОМ, набор 1

24 собственные иллюстрации по одобренному владельцем образцу: золотистый соболь,
тёмно-синий шарф, золотой значок геопозиции. Созданы встроенным генератором
изображений 26 октября 2026 года. Общий лист 4×6 разделён по фактическим промежуткам между рисунками.
Каждый стикер пропорционально вписан в 256×256 WebP с прозрачными полями
и сохранением альфа-канала. Подписи и порядок — в expressions.js.

Сюжеты: приветствие, кофе, мороз, благодарность, одобрение, прощание, объятия,
смех, ночь, утро, деревянный дом, прогулка у реки, автобус, радость, помощь,
вопрос, удивление, извинение, договорённость, «Я рядом», чай, дом, покупки,
фотография. Архитектура условная, это не фотографии конкретных зданий.

Это собственный набор платформы, доступный во всех городах. Изображения ВК,
герб города и чужие стикер-паки не копируются. Эмодзи — обычный Unicode;
их внешний вид определяется устройством пользователя.

Стикер сохраняется вместе с текстом как проверяемый идентификатор
`[ryadom-sticker:sable-NN]`. Рендер принимает только 24 локальных изображения,
не HTML и не произвольные ссылки. Запись и стикер проходят одну существующую
модерацию; права и схема базы не изменяются.
