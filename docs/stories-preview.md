# Пример историй жителей

Визуальный пробный режим, без API, Auth, Storage, записи в базы или публичных загрузок.

- Отдельная страница `/stories-preview/?city=Енисейск` с явной пометкой примера.
- На главной `/?stories=preview#/home?city=Енисейск`: полоса над «Город сегодня».
- На стене `/wall/?city=Енисейск&stories=preview`: полоса над записями.
- Без параметра `stories=preview` обе существующие страницы остаются без историй.
- Примеры используют существующие фотографии подборок Енисейска; в других городах — общие иллюстрации. Авторы не выдуманы: подпись «Пример».
- Можно открыть фото, перелистывать кнопками, стрелками клавиатуры или свайпом; автоматический переход через 7 секунд, пауза, Escape. При reduced-motion автопереход изначально выключен; скрытая вкладка не продвигает счётчик.
- JPG/PNG/WebP до 10 МБ проверяются декодированием. Своё фото видно только в текущем экземпляре блока и вкладке через Object URL. После обновления оно исчезает; URL освобождаются при замене, удалении и размонтировании.
- Подписи вставляются только через textContent. Нет загрузки в сеть, сохранения в local/sessionStorage или счётчиков/реакций с вымышленными данными.
- «24 часа после одобрения», настоящая очередь модерации, права авторов и городских модераторов, жалобы и приватное хранение ещё НЕ реализованы. Не выдавать этот пример за работающую публикацию историй.

Следующий этап после оценки интерфейса: отдельная защищённая схема и приватный Storage с серверной модерацией и сроком от published_at; применить к Production только после отдельного разрешения владельца. Не кодировать истории в обычных записях стены: их права/срок хранения отличаются.

Проверка: `python tests/stories-preview-browser.py` при запущенном Vite на 127.0.0.1:4178, Playwright 1.62.0/Chromium. Проверяется мобильный/desktop просмотр, пауза, клавиатура/возврат фокуса, локальное фото, экранирование подписи, ошибочный файл, отсутствие сетевых записей и сохранения после перезагрузки.
