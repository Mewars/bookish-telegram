# Модерация городской ленты: контекст и запрет самопроверки

В закрытой бете модератор должен видеть, к какой опубликованной записи относится комментарий: город, заголовок и текст исходной публикации. Без контекста невозможно надёжно оценить смысл комментария.

Проверка собственной публикации или комментария запрещена серверной функцией. Интерфейс должен явно объяснять это и не показывать активные кнопки одобрения/отклонения для собственных материалов. Вторая учётная запись редактора нужна для настоящей проверки.

Реальные права проверяются в PostgreSQL RLS и RPC, а не только на экране. До проверки с двумя независимыми аккаунтами, восстановления бэкапа и юридической готовности не открывать раздел в production.
