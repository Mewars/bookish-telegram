# Возврат из публичной карточки и сохранение каталога

Основа: `mewars`, `1ac29574ca369571dcb98469a9a9f943eaec49ef`.
Отдельное изменение от PR #151; изменения объявлений сюда не включены.

## Результат в коде

- Город, поиск, категория, подкатегория и дата каталога хранятся в hash-адресе. Фильтры заменяют текущую запись истории, а открытие карточки создаёт новую. Можно обновить страницу и использовать браузерные Back/Forward.
- В адресе карточки сохраняется проверяемый адрес исходного публичного списка. Кнопка возврата и Escape используют его. При прямом открытии карточки используется каталог её типа и текущего города. Домашние подборки и избранное, как и прежде, возвращают к каталогу типа карточки.
- Возврат разрешён только к спискам `places`, `events`, `services` того же города. Админка, профиль, внешние адреса и адреса других карточек игнорируются. Для кнопки возврата не вызывается слепой `history.back()`, поскольку предыдущая страница может оказаться административной или внешней.
- ID карточки больше не принимается под префиксами административных и прочих непубличных разделов. Обычный `#/admin` остаётся за существующей проверкой Auth/серверных прав.
- Выбор города записывается в отдельную запись истории. Back/Forward восстанавливает город из адреса, независимо от последнего выбора в localStorage. На стартовой странице без города адрес дополняется выбранным городом через replaceState.
- Подкатегории берутся исключительно из уже имеющихся значений `Категория / Подкатегория`. Справочник заведений и реальные организации не переклассифицируются. Исправление общего справочника — отдельная задача.
- Текст публичного каталога использует выбранный город вместо жёстко заданного Енисейска.
- Город добавляется в адрес только на главной и в публичных каталогах/карточках. Адреса входа, профиля и OAuth не переписываются; их прежний контракт сохранён.

## Проверки

Локально: полная регрессия — 440 тестов, без ошибок; линтер и TypeScript/Vite build. Шесть новых тестов включены в npm test: исходный/связанный список, подкатегория/дата, два текущих и условный будущий город, подмена return, прямые ссылки, маршруты с приватными префиксами и запись истории.

Добавлен отдельный read-only workflow `Public Catalog Navigation Browser`: Chromium 390/1440 px, реальная сборка с публичным локальным каталогом без облачных ключей, все внешние сетевые запросы блокируются. Проверяет фильтры, подкатегории, Back/Forward, Escape, перезагрузку, город и небезопасные ссылки. Локально Chromium не загрузился: скачанный архив оказался недоступным/неполным. Поэтому браузерный результат должен быть подтверждён этим workflow; до успешного завершения его не считать пройденным.

Базы, RLS, пользовательские данные, Auth и серверные функции не изменены. В существующей полной регрессии прошли тесты разграничения административного доступа и изоляции городов. Навигационная проверка не заменяет эти серверные ограничения.
