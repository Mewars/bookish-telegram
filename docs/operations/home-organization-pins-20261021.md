# Главная, заявки и закрепление объявлений

Обложка занимает первый экран до нижнего края окна; категории и кнопка добавления находятся внутри неё. Кнопка открывает существующий защищённый маршрут заявки #/add-organization. Категория и подкатегория выбираются из общего справочника; город берётся из текущего города платформы. Закрытые сведения и фотография остаются в заявке до проверки. При открытии заявки администратором сохраняются выбранная категория и раздел «Места»/«Услуги». Публикация выполняется прежней серверной функцией после ручной проверки.

Для объявлений подготовлены таблица classified_owner_pins и RPC owner_pin_classified. Прямое изменение закреплений закрыто; функция разрешает закреплять опубликованные объявления только активному глобальному владельцу. Закрепления скрытых объявлений публично не выдаются. Городской список загружает в том числе старые закреплённые объявления, не вошедшие в последние 100 записей.

SQL docs/sql/classified-owner-pins-v1.sql проверяется в изолированной базе. В облачные проекты он автоматически не применяется. Требуется отдельное разрешение владельца на изменение Production Supabase согласно передаче проекта. До применения таблицы опубликованный список работает как прежде, кнопка закрепления скрыта. После применения кнопка и метка появляются автоматически при обновлении списка.

Откат SQL: сначала вернуть предыдущий frontend, затем при необходимости DROP FUNCTION public.owner_pin_classified(uuid,boolean); DROP TABLE public.classified_owner_pins; — удалятся только закрепления, не объявления. Выполнять только по отдельному разрешению.
