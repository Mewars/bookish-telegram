# «Друзья рядом»: рабочее размещение на Sprinthost

Запуск подготовлен по отдельной просьбе владельца 17.10.2026: перейти от синтетических тестов к реальной функции на сайте. Вход остаётся существующим, production Supabase DB/Auth/OAuth/DNS и ключи не изменяются.

## Размещение и потоки данных

- В production только `VITE_FRIENDS_ENABLED=true` + `VITE_FRIENDS_BACKEND=host` + точный текущий production Auth backend. Статический Pages и Test RPC не включают этот production API автоматически.
- Браузер округляет GPS до двух знаков и отправляет на same-origin `/api/friends.php`. Код, связи, имена для друзей и точки хранятся в SQLite `/home/mewars/.ryadom-friends/friends.sqlite`, вне public_html. Каталог 0700, файл 0600; серверный код также вне public_html. Никаких геоданных в Supabase RPC или таблицах production.
- Сервер проверяет каждый bearer-токен через фиксированный Supabase Auth `/auth/v1/user` с TLS и без redirects. В Auth идут только токен и существующий публичный ключ, не тело запроса с координатами. Идентификатор берётся из проверенного ответа; user_metadata не даёт прав. Ошибка Auth закрывает доступ. Сервисных ключей нет.
- Действующая учётная запись остаётся в Supabase eu-west-1. Это не полная локализация всех данных платформы и не заключение о юридическом соответствии. Не выдавать локальное хранение геоданных за перенос аккаунтов.
- На friends-маршруте Metrika/Webvisor отключаются до рендера приватного экрана, включая переход с публичной страницы после согласия на аналитику. Контейнер дополнительно исключён из записи/сбора полей. Браузерная проверка использует SDK-spy без отправки данных в Яндекс.
- OpenStreetMap загружается отдельно по нажатию; имена/метки не включаются в tile URL. При выборе области карты провайдер получает IP и область. Отказ от подложки не включает GPS.

Возможности текущего аккаунта реально проверены: PHP 8.5, SQLite 3.51, curl, openssl, возможность приватного хранения: Actions 39027536390. Сведения провайдера о ЦОДах в России: https://sprinthost.ru/dc и https://sprinthost.ru/docs/SPH-dc_in_russia.pdf . Это не проверка договора оператора и всей цепочки обработки персональных данных.

## Доступ, согласие, сроки

Публичного поиска людей нет. Код 128 бит на сутки, дружба после подтверждения получателем. По умолчанию невидим. Явное действие выдаёт разовый токен согласия `FRIENDS-GEO-1.0` на 10 минут, которым можно записать ровно одну приблизительную точку на час. Старый токен/поздний GPS после скрытия не восстанавливает доступ. Блокировка/удаление дружбы прекращают серверный доступ сразу; снимок в открытом браузере друга обновляется раз в 30 секунд. Клиент дополнительно проверяет истечение.

Все операции сериализует SQLite BEGIN IMMEDIATE; права проверяются внутри транзакции. Предел: 60 запросов/минуту на подтверждённый UID, включая неудачные попытки, и 10 новых приглашений/сутки. Все SQL параметры связаны, ошибок SQL и токенов в HTTP ответах нет. POST-only, запрет чужого Origin, no-store, лимит JSON 8 KiB. GET health возвращает только ready/backend, без данных пользователей.

Скрытие удаляет точку сразу. Истечение ограничивается при каждом чтении независимо от cron; отдельный cron каждые пять минут удаляет истёкшие точки и токены/коды. У SQLite включён secure_delete; истории перемещений нет. Удаление данных раздела удаляет профиль и связанные заявки, связи, блокировки, точку. Чужие блокировки по тому же UID сохраняются до отмены их авторами; очистка своего профиля не позволяет их обойти. Лимит приглашений не сбрасывается при удалении профиля. Технический счётчик запросов сохраняется до суток после последнего обращения. Настройка резервных копий провайдера не меняется; удаление из всех backup данным кодом не гарантируется.

## Установка и откат

`scripts/install-friends-host.sh` запускается из проверенного deployment workflow до переключения HTML. Использует существующую SSH identity и публичный ключ приложения. Готовит только новый приватный каталог, переносит server/*.php, записывает config.json, создаёт пустую локальную базу и добавляет одну строку cron с точной меткой RYADOM_FRIENDS_EXPIRE_V1. Прочие задания сохраняет; неизвестную строку с той же меткой не заменяет. Не использует rsync --delete и не удаляет существующие пользовательские данные.

При ошибке установки деплой останавливается. Для отключения убрать production frontend-флаг и установить enabled=false в приватном config.json; после этого API отказывает, данные не удаляются автоматически. Удалять каталог или БД при откате нельзя. При удалении аккаунта через внешний Auth требуется также удалить связанные локальные данные; автоматического Auth webhook в этом выпуске нет.

## Проверка

`tests/friends-host.php` проверяет реальный SQLite: подтверждение, outsider-denial, округление, сроки, разовые токены, hide/replay, блокировки, лимиты и удаление раздела. JS проверяет транспорт и состояние ошибок.

`tests/local-e2e/friends-host.py` запускает настоящий PHP, соединённый только с локальным Auth. `FRIENDS_HOST_E2E=1` выполняет реальные браузерные сценарии двух пользователей с пятью синтетическими учётками, поддельный JWT, запрет чужого Origin, отмену позднего GPS, XSS-имя и удаление данных. Legacy Test RPC сценарии сохранены отдельно. Облачных фиктивных аккаунтов/точек не создаётся.

После публикации Published Home Browser QA проверяет основной сайт, вход в friends для гостя без GPS, health приватного хранилища и отказ анонимному API. Реальные GPS на физических телефонах владелец включает добровольно после входа; тест эмуляции GPS не выдавать за физический телефон.
