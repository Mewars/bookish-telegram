## Что фактически выполнено

Создан воспроизводимый изолированный стенд tests/local-e2e с настоящими
PostgreSQL 17, GoTrue Auth, PostgREST и Storage. Пять синтетических аккаунтов
созданы через настоящий Auth API; четыре отдельных браузерных контекста
прогоняют интерфейс реальной закрытой beta-сборки. Образы закреплены по digest;
порты только loopback; временные ключи вне Git; service key не попадает в браузер.
Все внешние запросы браузера запрещены, кроме тестового origin, который только
в Playwright перенаправляется на локальные сервисы. Production/удалённый
Ryadom-Test не используются и не меняются.

После первого успешного прототипа стенд полностью удалён и заново поднят
репозиторными скриптами с новыми контейнерами, ключами, БД и пользователями.
11 этапов прошли: вход, создание/редактирование черновика, приватность,
реальная галерея/Storage, фактическое истечение короткой ссылки, удаление фото,
сетевой сбой/повтор без дублей, отклонение/исправление/повторная подача,
межгородские права и публикация, двусторонний чат/защита от подмены,
блокировка переписки. Проверки отказов используют конкретные SQLSTATE/причины.

Стандартный Supabase CLI сначала не удалось запустить: PostgreSQL-образ
исчерпал диск при vfs-распаковке. Рабочий стенд использует компактный официальный
PostgreSQL и те же реальные Auth/PostgREST/Storage. При первом чистом запуске
устранена гонка readiness (ConnectionResetError во время старта сервиса).
Ни проверки, ни RLS не отключались.

Первый CI выявил ещё одну гонку: pg_isready без host принимал временный
Unix-socket init-сервер PostgreSQL за готовую БД. Проверка TCP 127.0.0.1
дожидается финального сервера. Короткий signed URL живёт 3 секунды, чтобы
первое чтение не зависело от округления времени до секунд.

## Границы результата

Это локальный browser/API/Storage E2E, не имитация серверных ответов. Однако
минимальные city-access/JWT зависимости задаются fixture SQL: стенд не является
полным клоном удалённой БД и всех её default grants/инфраструктуры. Автоподтверждение
синтетических email не доказывает доставку почты. Не подтверждены публичный
защищённый beta-host, физические устройства/сети РФ и юридическая допустимость
реальных ПД. Эти ворота не объявляются пройденными.

Сценарий добавлен в отдельный CI workflow, без публикации пакета/функций.
Финальные PR/коммиты/CI/merge/deploy записать в handoff описания PR после проверки.
