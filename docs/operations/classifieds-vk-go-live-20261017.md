## ВК — конкретный объём следующего этапа

- **VK ID:** сохранить текущий код и конфигурацию до сквозного теста на реальном пользователе. Подтвердить выдачу Supabase session, вход после перезагрузки, выход, повторный вход, тот же UUID, профиль/аватар/избранное; отдельно убедиться, что Яндекс ID и вход по почте не повреждены.
- **Городские VK-группы:** собственная группа ВК — отдельный канал (не заменяет каталог). По согласованному ТЗ редактор по отдельной явной команде может отправить **собственную городскую новость** после модерации. Автопубликации личных сообщений, личных объявлений и чужого контента без согласия не допускать.
- Для фактической интеграции нужны **точный ID/ссылка принадлежащей группы**, подтверждённые администраторские права и выбранный законный способ выдачи разрешений VK API. Права не подменяются пользовательскими токенами или секретами, записанными в Git. Пока ID/разрешения не подтверждены, нельзя делать вид, что кросс-постинг включён.
- Отдельные федеральная VK-группа для подключения партнёров и городские VK-группы для локального продвижения сохраняются как разные направления; тарифы/объявления не смешиваются с редакционными новостями.
