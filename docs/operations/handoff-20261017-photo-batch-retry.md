пакета. Галерея сразу удаляет этот префикс из выбранных файлов. Если следующий

## Границы

Подтверждённый префикс не повторяется в текущем экземпляре галереи. При закрытии
страницы очередь не сохраняется. Если сервер сохранил файл, но ответ потерялся,
состояние последнего неподтверждённого запроса по-прежнему неоднозначно; распределённая
идемпотентность требует отдельного решения. Ошибка cleanup может оставить резерв
без объекта: существующая галерея сообщает ошибку при подписании такого альбома.
Не считать этот PR решением всех orphan/transport сценариев.

Production DB/Auth, DNS, секреты и OAuth не менялись. Отдельный HTTPS beta-host,
тестовый Auth, юридическая допустимость реальных ПД и настоящий A/B/C E2E не
подтверждены. Следующий безопасный этап: восстановление просмотра при истечении
подписанных ссылок/ошибке декодирования изображения; затем контролируемый cleanup
неудачного резерва и изолированный multi-user E2E.

Точные PR/коммиты, CI, merge SHA и deploy записать в финальном handoff описания PR
после фактической проверки: этот файл не утверждает результат будущих запусков.
