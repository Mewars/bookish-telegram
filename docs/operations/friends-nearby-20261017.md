# Друзья рядом — закрытая версия, 17.10.2026

Раздел `#/friends` включается только с `VITE_FRIENDS_ENABLED=true` и точным backend Ryadom-Test `djqhixvlfsbvannoqdjw`. В production отображается заглушка, GPS не запрашивается. Код Leaflet загружается отдельно при открытии раздела.

## Поведение

- Личный код приглашения действует 24 часа, новый код отзывает старый. Получатель подтверждает дружбу; имя задаётся отдельно, без импорта адресной книги.
- По умолчанию человек невидим. «Показать друзьям на один час» запрашивает одно положение браузера и округляет его до двух знаков до передачи. Сервер повторяет округление. Это приблизительная область, не непрерывное отслеживание как в нативном приложении.
- Точка видна всем подтверждённым друзьям, в том числе добавленным в течение часа; это указано перед включением. Истории перемещений и фонового GPS нет.
- «Стать невидимым» удаляет точку и аннулирует разовый токен. Поздний ответ GPS/повтор токена не восстанавливает показ.
- Удаление и блокировка прекращают доступ на сервере сразу. Уже полученный снимок у друга может оставаться до обновления (30 секунд при открытой странице); истечение точки дополнительно проверяется клиентом каждые 5 секунд.
- Подложка OpenStreetMap загружается только отдельным нажатием с объяснением передачи IP и области карты. Имена и метки остаются в приложении. «Показать всех друзей» меняет область карты без запроса GPS.

## Данные и права

SQL: `docs/sql/friends-nearby-private-v1.sql`, применяется только к Ryadom-Test. Четыре приватные таблицы с FORCE RLS и без прямых прав даже для city editor. В `public` только invoker-обёртки; privileged-функции в private schema, пустой search_path, обязательная проверка auth.uid(). Доступ к координатам только через подтверждённую дружбу с проверкой блокировок. Не выводить координаты/коды/токены в логи.

Истечение ограничивается на каждом серверном чтении. Физическая очистка истёкших точек выполняется при чтении состояния; отдельный cron не добавлен. Это надо учитывать при утверждении хранения перед реальными данными.

## Проверка и выпуск

`npm run test:friends`: реальные SQL-сценарии PGlite и клиентские границы. `tests/local-e2e/friends.py`: реальные локальные Auth/Postgres/PostgREST, два браузера и пять синтетических аккаунтов, включая постороннего и редакторов двух городов. GPS эмулирован. Покрыты приглашения, отказ чужим, округление, согласие на карту, отзыв токена, поздний GPS, XSS-имя и блокировка.

В workflow Closed Beta Package флаг включён только для Test. ZIP не является опубликованным приложением. До реальных геоданных действуют условия из `closed-beta-package-and-release.md`: защищённый beta-host, правовое основание и локализация, доставка Auth email, приёмка владельцем с другим участником. Production DB/Auth/OAuth/DNS данным изменением не меняются.
