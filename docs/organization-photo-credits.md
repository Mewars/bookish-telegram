# Изображения организаций «Рядом» — принцип достоверности

14.10.2026 — по запросу владельца удалены все произвольные изображения Unsplash из карточек конкретных заведений (предыдущий PR #45). Отдельные «атмосферные» фото оказались нерелевантными и вводили пользователя в заблуждение.

- Реальная фотография Спасского монастыря из оригинальных материалов проекта **сохранена**.
- Остальные карточки используют нейтральные локальные SVG-заглушки до ручной загрузки **настоящих** фотографий через закрытую админку.
- Чужие фотографии из 2ГИС, VK и чужих сайтов без разрешения не используем.
- Загруженные самим администратором фотографии должны размещаться в Supabase Storage с авторизацией и строгими RLS-правилами.
- Схема фотоадминки и интерфейс развиваются независимо от статического каталога; нельзя включать браузерные права на запись без проверки аккаунта владельца и безопасного внедрения.
