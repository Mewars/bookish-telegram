# Бренд «Встречай»

Пользовательское название — **Встречай**, описание — «городская платформа».
Домен, API, идентификаторы, ключи браузерного хранилища и пользовательские данные сохранены.
Старые имена некоторых файлов и CSS-классов оставлены для совместимости ссылок и открытых вкладок.

## Логотип

`src/components/BrandLogo.tsx` — переиспользуемый SVG-логотип:

```tsx
<BrandLogo /> // Статичный, animated по умолчанию false.
<BrandLogo animated={section === 'home'} decorative /> // Только основной header.
<BrandLogo seasonal={false} /> // Без праздничной шапочки.
```

Название целиком переведено в SVG-контуры Nunito 850 (лицензия SIL OFL в `public/brand/OFL-Nunito.txt`).
Геометка — отдельный фирменный знак после «й». Геометрия букв не зависит от загрузки шрифтов.
Для светлой темы используется тёмный вариант, для тёмной — графитовый с металлическими бликами;
компактный вариант на телефонах имеет повышенную читаемость.

`src/components/brandLogo.css`: одна анимация 1,25 с только на явно включённом экземпляре.
Движение по дуге, сжатие и два уменьшающихся отскока; затем неподвижная конечная позиция.
Двигается только обёртка геометки, включая отдельную SVG-шапочку. Размер логотипа зарезервирован.
При `prefers-reduced-motion: reduce` сразу показана неподвижная конечная позиция.
Внутренние страницы, подвал, вход и другие экземпляры анимацию не включают.

## Праздничное оформление

В React передайте `seasonal={false}`. Чтобы отключить сразу для всех экземпляров,
измените значение по умолчанию `seasonal = true` на `false` в `BrandLogo.tsx`.
На отдельных HTML-страницах используется статичный `public/brand/scarivo-winter.svg`;
для обычного оформления замените его на `vstrechay-logo.svg`
(светлый вариант — `vstrechay-logo-light-plain.svg`).
Отдельные файлы: `vstrechay-hat.svg` — шапочка, `scarivo-pin-winter.svg` — геометка без шапочки,
`scarivo-pin.svg` — самостоятельная иконка без шапочки. Иконки приложения всегда без шапочки.

## Иконки и публикация

`public/app.webmanifest` и `public/notifications/manifest.webmanifest` используют прежние
`start_url`, `scope`, `display` и пути иконок существующего манифеста уведомлений.
PNG 192/512 и Apple 180 созданы из фирменного SVG; знак находится в безопасной центральной области.
SVG favicon статичен. Новый сервис-воркер и офлайн-кеш не добавляются.
Старая ссылка на отсутствующий `/pwa/register.js` не переносится при публикации.
Метка `v=vstrechay1` обновляет кеш логотипов, иконок и изменённых модулей.

В `host-public` включены публичные исходники отдельных страниц хостинга:
донат, уведомления, профиль и отзывы. Изменены фирменные тексты и ссылки на оформление;
адреса API, ключи, авторизация и платёжная конфигурация сохранены.
Публикация делает приватную резервную копию затрагиваемых модулей перед загрузкой.

## Проверки

`npm run build`, `npm run lint`, `npm test`.
`python tests/brand-logo-browser.py http://localhost:5180/` при запущенном Vite:
1440, 768, 390, 360 и 320 px, неподвижность соседних элементов, приземление и остановка,
статичные внутренние страницы и подвал, reduced motion, возврат на главную.
`scripts/check-published-brand.mjs` повторяет проверку на опубликованной версии;
`scripts/check-published-photos.mjs` проверяет прежние реальные фотографии.

Письма из внешних кабинетов отправителей и обновление уже установленных ярлыков iOS
требуют отдельной ручной проверки. Существующие пользовательские публикации не переименовываются.
