# Логотип «Встречай» из утверждённого образца

Название бренда — **Встречай**. Заголовок главной: **Встречай — твой город в одном месте**.
Домен, база, авторизация, маршруты, ключи хранения и пользовательские публикации сохранены.

## Графика

Используются подготовленные графические слои на основе приложенного пользователем образца:
бело-серебряная объёмная надпись с золотым низом, золотая геометка и реалистичная шапочка.
Буквы не рисуются HTML-текстом или CSS-градиентами. Фон основного логотипа прозрачный.

- `public/brand/vstrechay-wordmark.webp` — надпись, 1124×300.
- `vstrechay-wordmark-compact.webp` — пропорциональная мобильная версия 562×150.
- `vstrechay-pin-holiday.webp` — геометка вместе с шапочкой, 224×300.
- `vstrechay-pin-plain.webp` — тот же знак без шапочки.
- `vstrechay-logo.webp` / `vstrechay-logo-plain.webp` — статичные композиции с тем же расположением слоёв.
- `vstrechay-icon-{16,32,48,128,180,192,512}.png` — квадратная иконка с геометкой и шапочкой.
- `public/favicon.ico` — контейнер PNG-размеров 16, 32 и 48.

Некоторые прежние SVG-пути сохранены для совместимости открытых вкладок и отдельных HTML-страниц.
Это SVG-контейнеры подготовленных изображений, а не прежняя векторная надпись.
В частности, `scarivo-winter.svg` содержит текущую статичную композицию;
`scarivo-pin.svg` — текущую квадратную иконку. Старые названия файлов не показываются пользователю.
Архив `vstrechay-favicon-kit.zip` среди полученных вложений отсутствовал; размеры экспортированы из образца.

## Компонент и анимация

`src/components/BrandLogo.tsx`:

```tsx
<BrandLogo /> // Статичный; animated по умолчанию false.
<BrandLogo animated={section === 'home'} decorative /> // Только основной header.
<BrandLogo holidayMode={false} /> // Без праздничной шапочки.
```

Существующий `seasonal={false}` также поддерживается. `holidayMode` имеет приоритет.
Праздничная графика геометки включает шапочку; переключение не меняет её зарезервированный контейнер.
Шапочка и геометка движутся вместе. Надпись — отдельное неподвижное изображение.

CSS-анимация `vstrechay-pin-arrive` длится 1,25 с: прилёт по дуге, небольшое сжатие,
два затухающих отскока, неподвижная конечная позиция. Повторного цикла нет.
Трансформации не меняют размеры логотипа, города и header.
При `prefers-reduced-motion: reduce` сразу показана статичная конечная позиция.
Во внутренних разделах, подвале, авторизации, административном интерфейсе и меню анимация выключена.

Для отдельных HTML-страниц без React обычное оформление включается заменой `scarivo-winter.svg`
на `vstrechay-logo.svg`. Все композиции используют одинаковые пропорции 562×150.
Иконки favicon и PWA всегда статичны, праздничный вариант соответствует последнему ТЗ.

## PWA и кеш

Стартовый адрес, scope, display и прежние пути PWA-иконок сохранены.
`public/app.webmanifest`, `public/notifications/manifest.webmanifest`, Apple Touch Icon и favicon обновлены.
Метка ресурсов `v=vstrechay2` обновляет кеш оформления и изменённых модулей хостинга.
Перед публикацией сохраняется приватная резервная копия затрагиваемых ресурсов.

## Проверка

`npm run build`, `npm run lint`, `npm test`, `python tests/preserve-host-extensions.py`.
`python tests/brand-logo-browser.py http://localhost:5180/` проверяет 1440/768/390/360/320 px,
прилёт, отскок и остановку, неподвижные буквы/header/город, reduced motion, подвал и внутренние маршруты.
`scripts/check-published-brand.mjs` проверяет опубликованные HTML-страницы, манифесты, иконки и анимацию.
`scripts/check-published-photos.mjs` проверяет сохранённые реальные фотографии карточек.

Письма во внешних кабинетах отправителей, системный кеш уже установленных ярлыков iOS
и физические устройства требуют ручной проверки. Пользовательские данные и публикации не переименовываются.
