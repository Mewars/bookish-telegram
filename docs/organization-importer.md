# Локальный импорт организаций

Маршрут: `#/admin/import`. Ссылки в публичной навигации нет. Это внутренний
инструмент владельца, но скрытый маршрут не является авторизацией.

1. Скачать шаблон или выбрать/перетащить один CSV до 5 MB (5 × 1024 × 1024 байт).
2. Проверить статусы, конкретные проблемы и возможные дубли в таблице.
3. Открыть «Исправить», изменить значения, сохранить. Проверки всего файла,
   включая дубли, пересчитываются. Подтверждение права использования сбрасывается.
4. Подтвердить право использования и скачать JSON. Строки с ошибками исключаются;
   предупреждения и дубли не блокируют экспорт и не удаляются автоматически.

Данные хранятся в React state и исчезают при reload, выходе с маршрута или очистке.
Ничего не добавляется в `catalog.ts`, Supabase или production-каталог.

## CSV

UTF-8, с BOM или без; CRLF/LF; `;` или `,` определяется автоматически по заголовкам
и согласованности колонок. Двойные кавычки защищают разделители/переносы строк;
`""` внутри quoted field означает одну кавычку. Некорректные кавычки отвергаются.
Пустые строки пропускаются. Номера в таблице — номера записей с учётом заголовка,
без пустых строк (переносы внутри quoted fields не создают новые записи).

| Русский заголовок | Machine name | Обязательно |
| --- | --- | --- |
| Название | title | Да |
| Город | city | Да |
| Категория | category | Да |
| Адрес | address | Нет |
| Телефон | phone | Нет |
| Часы | hours | Нет |
| Сайт | website | Нет |
| VK | vkUrl | Нет |
| Описание | description | Нет |
| Широта | lat | Нет |
| Долгота | lon | Нет |
| Источник | sourceUrl | Да |
| Тип источника | sourceType | Да |
| Дата проверки | verifiedAt | Нет |

Регистр и пробелы заголовков не учитываются. Повторные известные колонки и
отсутствующие обязательные колонки блокируют загрузку. Неизвестные колонки
пропускаются с заметкой. Несовпадение числа полей с заголовками делает строку
ошибочной до проверки и сохранения в форме; лишние колонки не экспортируются.
Поля обрезаются только по краям; внутреннее форматирование телефона сохраняется.

Шаблон содержит одну демонстрационную организацию с источником `https://example.ru`
и датой `2026-10-10`. Дата не подставляется в импортируемые записи автоматически.

## Валидация

- Непустые title/city/category/sourceUrl/sourceType.
- Только `owner_provided`, `official_website`, `official_social`,
  `government_open_data`, `manual_verified`. Понятные подписи есть в интерфейсе.
- website/vkUrl/sourceUrl: синтаксическая проверка абсолютного HTTP(S) URL,
  без credentials и пробелов; HTTP вызывает предупреждение. VK — только vk.com,
  vk.ru и их поддомены с проверкой границы hostname. URL не открываются и не запрашиваются.
- Координаты необязательны, но нужны обе: lat −90…90, lon −180…180.
  Десятичные числа с точкой, без NaN/Infinity/hex. Никакого геокодинга.
- verifiedAt: существующая календарная дата YYYY-MM-DD. Отсутствие — предупреждение;
  неправильная заполненная дата — ошибка.
- Дубли: нормализованные название + город + адрес, а при отсутствии адреса —
  название + город. Нормализация включает Unicode NFKC, регистр и повторные пробелы.
  Предупреждение получают обе строки. Число дублей — число отмеченных организаций.
  Для каждой строки показывается один совпавший номер, без длинных списков дублей.

## JSON

Массив `OrganizationImportRecord`, отдельный от `Item` и каталога:

```json
[
  {
    "title": "Пример организации",
    "city": "Енисейск",
    "category": "Кафе",
    "coordinates": { "lat": 58.45, "lon": 92.17 },
    "sourceUrl": "https://example.ru",
    "sourceType": "official_website",
    "verifiedAt": "2026-10-10"
  }
]
```

Непустые optional address/phone/hours/website/vkUrl/description/verifiedAt
включаются; пустые поля отсутствуют. Координаты — числа в `coordinates`,
а не строки lat/lon. Общий тип `SourceMetadata` готовит sourceUrl/sourceType/
verifiedAt/updatedAt для будущего хранения provenance. Он также расширяет `Item`,
не меняя данные существующих карточек; updatedAt не генерируется импортёром.

Имя: `ryadom-organizations-YYYY-MM-DD.json` (дата скачивания в локальной зоне браузера).
Скачивание через Blob/ObjectURL; ссылка удаляется, URL освобождается спустя 1 секунду.

## Приватность и безопасность

Модули импорта не используют fetch, XHR, backend, сторонние API или SDK.
Чтение — File.arrayBuffer + UTF-8 TextDecoder. URL используются только как текст
для проверки, а в предпросмотре выводятся без ссылок. Нет загрузки фотографий,
геокодинга, автоматического поиска, scraping, аналитических событий или логов CSV.

RootRoute загружает публичное приложение лениво: при прямом входе в импортёр
Auth/Supabase/Music-провайдеры даже не инициализируются. Существующий глобальный
Telegram SDK из index.html не используется для отправки данных импорта.

Метрика/Webvisor отключается до рендера импортёра, в том числе при переходе с
публичной страницы с уже принятым согласием. Guard в enabled() исключает маршрут;
при выходе аналитика снова работает по прежнему согласию. Дополнительно контейнер
помечен ym-disable-keys/ym-disable-clicks/ym-disable-webvisor.

Все значения отображаются обычным React rendering. HTML/JS/формулы не выполняются.
Данные CSV/организации не записываются в localStorage; сохраняется только настройка темы.
Подтверждение прав изначально выключено и сбрасывается при замене файла или исправлениях.
Это подтверждение не заменяет юридическую проверку источника.

## Проверки

```sh
npm run test:import
npm run build
npm run lint
git diff --check
```

Unit-тесты покрывают UTF-8/BOM/CRLF/LF, delimiters, quoted/multiline/escaped text,
пустые optional поля, URL/VK, координаты и неполные пары, sourceType, даты,
дубли после редактирования, размер файла, пустой CSV/только заголовки,
HTML/формулы как текст, фильтрацию ошибок и отсутствие пустых optional полей в JSON.
Loader тестов использует уже установленный TypeScript, без новой зависимости.

Браузерная проверка Chromium: 320/390/768/1024/1440, light/dark; загрузка,
редактирование, drop, скачивание шаблона/JSON, checkbox, отсутствие горизонтального
переполнения страницы, большие/пустые/не-UTF-8 файлы, очистка после reload,
возврат фокуса, отсутствие ошибок JS. Отдельно проверяется production origin
с согласием на аналитику: прямой вход и переход с публичной страницы, отключение
и восстановление Метрики. Во время импорта/редактирования/экспорта — ноль запросов.
