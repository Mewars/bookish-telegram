# Scarivo — временный ребрендинг
Публичный бренд: **Scarivo**. Домен **ryadomcity.ru** и технические имена Supabase, OAuth, localStorage, SQL, Storage, DNS не менять в рамках ребрендинга.

- `scarivo-winter.svg` — геометка + фирменная надпись и красная новогодняя шапка на S, прозрачный фон; никаких внешних шрифтов/ресурсов.
- `scarivo-pin.svg` — компактная геометка с S, используется как favicon и иконка.
- Зимние фоны Енисейска, Лесосибирска и Красноярска, снег, часы, фонари и согласованная композиция не изменяются.
- `scarivo-share-pin.png` на этапе безопасного ребрендинга использует старую нейтральную (без слова РЯДОМ) геометку в PNG для Open Graph; PNG должен быть перерисован после финального утверждения фирменного знака.

Оригинальные архивные ассеты не удалены, чтобы сохранить возможность отката; ссылки на старые словесные логотипы должны быть убраны из видимого интерфейса.
