# Компактное управление музыкой

Убрана постоянная надпись «Плеер остаётся активным» в навигационном модуле хостинга. В полосе возврата из городского раздела остаётся компактная кнопка музыки. Управление паузой, звуком и громкостью появляется для открытого или активного плеера. При скрытом остановленном плеере дополнительные кнопки не занимают место.

Навигация продолжает открывать существующие разделы в том же iframe, сохраняя корневую React-программу. Кнопки используют тот же audioPlayer и его фактическое состояние через события текущего документа; второй audio не создаётся. Открытие настроек возвращает пользователя из раздела и действительно открывает существующий плеер. Постоянная строка подсказки в самом плеере заменена сообщением только при загрузке или ошибке.

Play/Pause и громкость сохраняются при внутренних переходах. Громкость также сохраняется в прежнем ключе localStorage. Автоматического запуска после обновления страницы нет: браузеры требуют действие пользователя. Сохранение звука после полной перезагрузки страницы, закрытия вкладки или ограничения фоновой работы телефоном не обещается.

## Выпуск

- host-public/ui/site-shell.js содержит действовавший на хостинге модуль с точечными изменениями управления музыкой. Навигация, уведомления и ссылка доступности в подвале сохранены.
- При сохранении расширений хостинга ссылка site-shell.js получает новую версию запроса v=20261021music1, чтобы браузер не использовал старую плашку из кеша.
- Копия frontend для отката дополнена ui/site-shell.js. Остальные файлы каталога ui не заменяются.
- Изменений базы, секретов и пользовательских данных нет.

## Проверки

Модульный тест использует синтетические аудиособытия: фактический playing обязателен для статуса воспроизведения; проверяются пауза, громкость, mute, повторное подключение слушателей и запоздалый отказ play().

Браузерный сценарий использует настоящие React-программу и site-shell.js, синтетический Audio и локальные заглушки содержимого iframe. На экранах 360/390/1440 проверяются отсутствие плашки, отсутствие переполнения, один аудиообъект при переходах, пауза, звук, громкость и ошибка потока. Эти проверки не подтверждают доступность радио в сети пользователя или фоновое воспроизведение на физическом телефоне.
