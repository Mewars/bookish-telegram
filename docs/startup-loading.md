# Индикатор первой загрузки

`RootRoute` сохраняет выбор публичного приложения / служебного импорта. Вместо видимой надписи «Загружаем Рядом…» его Suspense fallback показывает исходную золотую геометку `public/brand/pin-yellow.svg` (42 × 49 px) по центру видимого окна на тёмно-синем фоне. Скрытый текст «Загрузка приложения» внутри `role="status"` доступен экранной читалке. CSS transform поднимает геометку на 16 px, при приземлении слегка сжимает её; овальная тень движется синхронно. Цикл — 1,2 секунды. `prefers-reduced-motion: reduce` отключает обе анимации. Дополнительной задержки перед показом сайта нет.

Ошибка отложенной загрузки `PublicApplication` заменяет индикатор коротким сообщением и кнопкой «Повторить загрузку». Предельное ожидание — 20 секунд; таймер очищается при успехе/ошибке. Поздний ответ не возвращает уже отклонённую загрузку в успешное состояние. Повтор выполняется полной перезагрузкой страницы, чтобы сбросить сохранённую React.lazy ошибку; автоматических циклических попыток нет.

Прямой `#/admin/import` остаётся вне Suspense, ограничения ожидания и границы ошибок публичного приложения. Страница импорта, Auth/Supabase, бизнес-логика и существующие маршруты не изменены. Обработка относится к отложенному модулю после запуска React.

## Проверено

- `npm ci`, `npm run lint`, `npm run build`, `npm run test` (55 тестов), `git diff --check` — успешно.
- Новые unit-тесты: успешная загрузка; отказ/синхронное исключение; неотвечающий модуль; позднее завершение после timeout.
- Production-сборка, Chromium/Playwright: 8 задержанных загрузок на ширинах 320/390/768/1440 px с обычной и reduced motion настройкой. Нет видимой старой надписи, горизонтальной прокрутки или необработанных JavaScript-ошибок; скрытая подпись есть в accessibility tree.
- Отказ сетевого запроса и некорректный JavaScript публичного модуля дают состояние ошибки, без оставшегося индикатора. Кнопка перезагрузки восстанавливает главную после доступности модуля.
- Зависший запрос достигает настоящего ограничения 20 секунд при продвижении тестовых часов браузера и также показывает ошибку.
- Прямой importer при блокировке публичного модуля работает: 0 запросов PublicApplication, 0 запросов Supabase, без индикатора/ошибки публичного приложения.
- Регрессия обычного сайта: поиск, фильтры, избранное, навигация, гостевой режим/вход/согласия, карты, музыка, Telegram и CSV-import — успешно, без реальных входов/записей в БД.
- Проверка 390 px выполнена в Chromium, не на физическом iPhone/Safari. Production не размещался.

## Проверка движения и демонстрация

Chromium/Playwright с сенсорной мобильной эмуляцией: 320×568, 390×844, 768×1024, 1440×900 и landscape 844×390. Центр сцены совпадает с центром viewport; переполнения нет. Проверены CSS-кадры: подъём 16 px, сжатие по вертикали/расширение по горизонтали при приземлении, уменьшение тени наверху и расширение внизу. Обе анимации имеют период 1200 ms. Исходный SVG, 20-секундный timeout, граница ошибок и кнопка повторной загрузки не изменены.

[Короткая демонстрация — MP4, 2,4 секунды](screenshots/pin-loading/demo.mp4) собрана из кадров CSS-анимации Chromium, 25 fps, два цикла. Видео служит только для ревью и не используется сайтом.
