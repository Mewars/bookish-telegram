# Городская лента «РЯДОМ» — первая закрытая реализация

Раздел «Новости» и общегородская лента по ТЗ. Первое окружение — **только Ryadom-Test** (`djqhixvlfsbvannoqdjw`). Производственная база `cptbmepnbzogqkfhflsg` и публичное меню не меняются.

## Модель данных v1

- `community_posts`: тип `post` (публикация жителя), `question` (вопрос), `news` (редакционная новость), город, заголовок, текст, автор, статус.
- `community_comments`: комментарии к конкретному посту, автор, текст, статус модерации.
- Публикации жителей создаются только через `create_community_post` с лимитом **10 новых черновиков за сутки на аккаунт**, затем `draft → pending → published/rejected`. Самостоятельно опубликовать свою запись, подменить автора или выдать себя за редакцию нельзя.
- Новость `news` публикуется только через `publish_city_news` проверенным редактором соответствующего города; автор и редакционный тип фиксируются сервером.
- Комментарии создаются только через `submit_community_comment`, проходят модерацию, ограничены двадцатью в час на аккаунт. Администратор чужого города не видит неопубликованные материалы.
- `review_community_post` и `review_community_comment` проверяют права пользователя в PostgreSQL; автор не может модерировать собственные публикации/комментарии.
- Публичный читатель видит только опубликованные публикации и прошедшие модерацию комментарии внутри опубликованных публикаций.

## Что ещё не реализовано

- Публичная лента и форма публикации в мобильном интерфейсе (следующий PR).
- Фото постов (только собственные фото с безопасным Storage), реакции, жалобы, контроль блокировок в комментариях.
- Проверка с реальными отдельными аккаунтами, антиспам публикаций, правила площадки и удаление по требованию.
- VK кросс-постинг только после проверки прав на группу, официального API и согласия автора.
- Публичный запуск только после тестов RLS, прав доступа и восстановления отдельной резервной копии.

## Проверка

`npm run test:community`: тесты PGlite с настоящим PostgreSQL, имитация различных ролей, запрет самопубликации, новостей без полномочий, чтения непринятых комментариев, межгородской модерации.
`npm test`, `npm run lint`, `npm run build` — общие проверки.

При появлении ошибок в тестах сначала исправлять в отдельной ветке; **не применять миграцию к Ryadom-Test до успешного CI**.


## Контекст модерации комментариев (15.10.2026)

- Редактор в закрытой очереди комментариев видит город, тип, заголовок и текст опубликованного родительского поста. Контекст доступен через PostgREST FK JOIN с действующими RLS; черновики и материалы других городов не открываются.
- Интерфейс не показывает кнопки модерации собственного комментария и собственной публикации. SQL RPC продолжает самостоятельно проверять авторство и права.
- Тест `tests/community-moderation-context.test.mjs` проверяет запрос контекста, видимость ограничений и блокировку публичного запуска; включён в `npm run test:community`.
- Это автоматические тесты с имитацией запросов; настоящие два аккаунта, физические смартфоны и реальные операции через PostgREST в этом PR ещё не проверялись. Бета остаётся закрытой.
